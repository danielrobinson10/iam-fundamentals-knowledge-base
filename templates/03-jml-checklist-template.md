# Joiner-Mover-Leaver Checklist Template

## Joiner Checklist

- [ ] HR event received
- [ ] User account created
- [ ] Birthright access assigned
- [ ] Department group assigned
- [ ] MFA enrollment required
- [ ] Manager approval documented
- [ ] Access provisioning logged

## Mover Checklist

- [ ] Role or department change confirmed
- [ ] Existing access reviewed
- [ ] Unneeded access removed
- [ ] New access requested
- [ ] Manager approval documented
- [ ] Privileged access reviewed
- [ ] Audit evidence saved

## Leaver Checklist

- [ ] Termination notice received
- [ ] Account disabled
- [ ] Sessions revoked
- [ ] Group memberships removed
- [ ] Application access removed
- [ ] Privileged access removed
- [ ] Audit evidence saved
