# Privileged Accounts

## Overview

Privileged accounts have elevated permissions and are major targets for attackers.

## Common Types of Privileged Accounts

### System Administrators

System administrators control operating systems, servers, and network devices.

### Database Administrators

Database administrators manage database platforms and may have access to sensitive stored data.

### Application Administrators

Application administrators control enterprise applications and business-critical functions.

### Emergency Accounts

Emergency accounts, also called break-glass accounts, are used during crisis situations and often have powerful access.

## Risk Table

| Account Type | Risk | Example Control |
|---|---|---|
| System Administrator | Full system control | MFA, vaulting, session monitoring |
| Database Administrator | Sensitive data access | Approval workflow and logging |
| Application Administrator | Business application control | Least privilege and access reviews |
| Emergency Account | High-impact emergency access | Strict monitoring and limited use |

## Key Takeaways

- Privileged accounts are high-value targets.
- They should be inventoried, monitored, and reviewed.
- Emergency access should be controlled and audited.
