# IAM Glossary

## IAM

Identity and Access Management. Policies, processes, and technologies used to manage identities and access.

## IAAA

Identification, Authentication, Authorization, and Accounting.

## Identification

The process of claiming an identity.

## Authentication

The process of proving a claimed identity.

## Authorization

The process of determining what an authenticated user can access.

## Accounting

Tracking and logging user activity.

## SSO

Single Sign-On. Allows users to access multiple applications after signing in once.

## MFA

Multi-Factor Authentication. Requires more than one factor to verify identity.

## RBAC

Role-Based Access Control. Assigns access based on job roles.

## DAC

Discretionary Access Control. Resource owners determine access.

## MAC

Mandatory Access Control. System-enforced access based on labels and clearance.

## PAM

Privileged Access Management. Controls and monitors privileged access.

## JIT

Just-in-Time access. Temporary access granted only when needed.

## IGA

Identity Governance and Administration. Combines lifecycle management and access governance.

## SAML

Security Assertion Markup Language. Commonly used for enterprise SSO.

## OAuth 2.0

Authorization framework for delegated access.

## OIDC

OpenID Connect. Authentication layer built on OAuth 2.0.

## SCIM

System for Cross-domain Identity Management. Standard for automated user provisioning.
