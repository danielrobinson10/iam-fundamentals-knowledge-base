# Identification

## Overview

Identification is the first step in the access control process. It establishes who a user claims to be.

## Identity Creation

Identity creation is the process of registering or provisioning a user account.

Examples:

- Creating a username
- Creating a company email
- Assigning an employee ID
- Creating an account in an identity provider

## Identity Proofing

Identity proofing verifies that a person is who they claim to be in the real world.

Examples:

- Document verification
- Driver's license verification
- Knowledge-based verification
- HR validation during onboarding

## Identity Maintenance

Identity maintenance involves updating user information throughout the lifecycle.

Examples:

- Name changes
- Phone number changes
- Department changes
- Password resets
- Role updates

## Identity Retirement

Identity retirement is the proper removal or disabling of unused identities.

Examples:

- Disabling a terminated employee account
- Removing stale accounts
- Removing contractor access after a project ends

## Key Takeaways

- Identification starts the access control process.
- Digital identities must be created, maintained, and retired.
- Poor identity management can create security and compliance risks.
