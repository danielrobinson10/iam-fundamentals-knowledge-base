# Identity Lifecycle Management

## Overview

Identity lifecycle management controls access from the time a user joins an organization until they leave.

This is often called the Joiner-Mover-Leaver process.

## Joiner

A joiner is a new employee, contractor, or user.

Common steps:

- Create user account
- Assign initial access
- Add department groups
- Require MFA enrollment
- Document approvals

## Mover

A mover is a user whose role, department, or responsibilities change.

Common steps:

- Review existing access
- Remove access no longer needed
- Add new access based on role
- Review privileged access
- Update approvals and records

## Leaver

A leaver is a user who exits the organization.

Common steps:

- Disable account
- Revoke sessions
- Remove group memberships
- Remove application access
- Remove privileged access
- Preserve audit evidence

## Automation

Lifecycle automation can reduce security risk and administrative overhead. Automation may use tools, workflows, scripts, or identity governance platforms.

## Key Takeaways

- Joiners need correct access quickly.
- Movers need access updated carefully.
- Leavers must have access removed quickly.
- Lifecycle management supports least privilege and audit readiness.
