# IAAA: Identification, Authentication, Authorization, and Accounting

## Overview

IAAA is a core framework for controlling access to systems and data.

IAAA stands for:

- Identification
- Authentication
- Authorization
- Accounting

## Identification

Identification is the process of claiming an identity in a system.

Examples:

- Username
- Email address
- Employee ID
- Account ID

## Authentication

Authentication verifies that the user is who they claim to be.

Examples:

- Password
- MFA
- Fingerprint
- Face ID
- Hardware token

## Authorization

Authorization determines what a verified user is allowed to access.

Examples:

- Access to a finance application
- Permission to reset passwords
- Ability to read but not edit a document
- Admin access to a system

## Accounting

Accounting tracks user activities for security, compliance, and investigation purposes.

Examples:

- Login logs
- Access logs
- Audit trails
- Change records

## Simple Example

A user enters their username. This is identification.

The user enters a password and approves MFA. This is authentication.

The system checks the user's group membership and grants access to the correct application. This is authorization.

The system records the login time and accessed resource. This is accounting.

## Key Takeaways

- Identification establishes who the user claims to be.
- Authentication proves the identity.
- Authorization controls access.
- Accounting records activity.
