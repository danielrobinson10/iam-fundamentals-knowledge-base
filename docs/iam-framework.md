# IAM Framework

## Overview

A strong IAM framework combines identity management, access management, governance, and security infrastructure.

## Identity Management

Identity management covers the creation, management, and retirement of user identities throughout their lifecycle.

Examples:

- Creating new user accounts
- Updating user attributes
- Managing group membership
- Disabling accounts during offboarding

## Access Management

Access management controls authentication and authorization to protected resources.

This includes:

- Verifying user identity
- Determining what users are allowed to access
- Applying access policies
- Enforcing MFA and SSO

## Governance

Governance ensures identity and access practices follow policies, compliance requirements, and risk controls.

This includes:

- Access reviews
- Approval workflows
- Segregation of duties
- Audit reporting
- Role management

## Security Infrastructure

IAM depends on supporting security technologies such as:

- Authentication servers
- Directory services
- Firewalls
- User databases
- Identity providers
- Logging and monitoring systems

## Key Takeaway

A strong IAM framework helps protect sensitive data, prevent unauthorized access, manage privileges, and maintain compliance.
