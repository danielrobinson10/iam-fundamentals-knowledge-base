# Privileged Access Management Basics

## Overview

Privileged Access Management, or PAM, protects accounts with elevated access to critical systems.

PAM recognizes that privileged users create greater risk than standard users because they can make major system changes, access sensitive data, and bypass normal restrictions.

## Definition

PAM includes the strategies, policies, and tools used to protect, control, and monitor privileged access.

## Key Components

### Privileged Account Discovery

Identifying and cataloging all privileged accounts across the organization.

### Password Vaulting

Securely storing and managing privileged credentials.

### Session Management

Monitoring and controlling privileged user sessions.

### Just-in-Time Access

Granting temporary privileged access only when needed.

### Monitoring and Auditing

Tracking privileged activity for security investigation and compliance reporting.

## Why PAM Matters

If a privileged account is compromised, the damage can be significant. PAM reduces this risk by limiting, monitoring, and controlling privileged access.

## Key Takeaways

- PAM protects high-risk accounts.
- Privileged accounts require stronger controls than standard accounts.
- PAM supports auditing, monitoring, and compliance.
