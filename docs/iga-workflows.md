# IGA Workflows

## Overview

IGA workflows help ensure access requests are handled efficiently, securely, and in alignment with policies.

## Access Request Workflow

1. User or manager initiates an access request.
2. System checks the request against access policies.
3. Segregation of duties rules are evaluated.
4. Request is routed to the correct approver.
5. Approved access is provisioned.
6. Action is logged for audit evidence.

## Workflow Table

| Step | Purpose |
|---|---|
| Access Request | Starts the request process |
| Policy Validation | Checks the request against rules |
| Approval Routing | Sends request to the correct approver |
| Provisioning | Grants approved access |
| Audit Logging | Records the access change |

## Analytics and Reporting

IGA reporting can provide insight into:

- High-risk access combinations
- Access review completion
- Compliance status
- Unusual access behavior
- Dormant accounts
- Privilege creep

## Key Takeaways

- IGA workflows help standardize access requests.
- Approval routing supports accountability.
- Audit logs support compliance and investigation.
- Analytics help identify risky access.
