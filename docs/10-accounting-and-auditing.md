# Accounting and Auditing

## Overview

Accounting tracks user activity for security, compliance, and investigation purposes.

## Access Logging

Access logs should capture:

- Who performed the action
- When the action happened
- What action was taken
- Which resource was accessed

## Audit Requirements

Strong audit practices include:

- Log integrity protection
- Defined retention periods
- Regular log review
- Forensic readiness

## Compliance Benefits

Accounting and auditing support:

- Regulatory compliance
- Incident investigation
- Pattern analysis
- Security control validation
- Root cause analysis after security events

## Example Log Fields

| Field | Purpose |
|---|---|
| User ID | Identifies who performed the action |
| Timestamp | Shows when the action occurred |
| Action | Describes what happened |
| Resource | Shows what system or data was accessed |
| Result | Shows whether the action succeeded or failed |

## Key Takeaways

- Accounting provides visibility into user activity.
- Logs support security investigations and compliance.
- Logs should be protected from tampering.
- Regular review helps detect suspicious activity.
