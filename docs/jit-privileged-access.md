# Just-in-Time Privileged Access

## Overview

Just-in-Time, or JIT, privileged access grants elevated permissions only when needed and only for a limited period.

## JIT Workflow

1. User requests temporary privileged access.
2. User provides a business justification.
3. Request is routed to an authorized approver.
4. Approved access is granted for a limited time.
5. Privileges automatically expire.
6. Activity is logged and reviewed.

## Benefits

JIT access helps reduce:

- Standing privileges
- Attack surface
- Insider misuse
- Long-term exposure from compromised accounts

## Example

An IT administrator needs elevated access to troubleshoot a server issue. They request access for two hours, provide a justification, complete MFA, receive approval, and the access automatically expires after the time window.

## Key Takeaways

- JIT access provides temporary elevation.
- It supports least privilege.
- It reduces the risk of standing admin access.
- It should be logged and reviewed.
