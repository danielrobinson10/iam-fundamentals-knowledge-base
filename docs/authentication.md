# Authentication

## Overview

Authentication is the process of verifying a user's claimed identity.

## Authentication Factors

### Knowledge Factors

Knowledge factors are things the user knows.

Examples:

- Passwords
- PINs
- Security questions

These are common but can be weak if used without strong policies or MFA.

### Possession Factors

Possession factors are things the user has.

Examples:

- Mobile device
- Smart card
- Hardware token
- Authenticator app

### Inherence Factors

Inherence factors are things the user is.

Examples:

- Fingerprint
- Facial recognition
- Voice pattern

### Contextual Factors

Contextual factors use environmental attributes to evaluate risk.

Examples:

- Location
- Time of access
- Device characteristics
- Network information

## Why Context Matters

Contextual factors can help detect unusual behavior, such as a user signing in from an unfamiliar location or device.

## Key Takeaways

- Authentication proves identity.
- MFA improves authentication security.
- Different factors provide different levels of assurance.
- Authentication controls should match the risk level of the resource.
