# Authorization

## Overview

Authorization determines what an authenticated user is allowed to access.

## Discretionary Access Control

Discretionary Access Control, or DAC, allows resource owners to determine who can access their resources.

Example:

A file owner grants another user permission to read or edit a file.

## Mandatory Access Control

Mandatory Access Control, or MAC, uses system-enforced rules based on security labels and clearance levels.

Example:

A government system restricts access based on classification level.

## Role-Based Access Control

Role-Based Access Control, or RBAC, assigns permissions to roles. Users are then assigned to those roles.

Example:

A Finance Analyst role receives access to finance applications and documents.

## Comparison Table

| Model | Who Controls Access? | Common Use |
|---|---|---|
| DAC | Resource owner | File sharing and collaboration |
| MAC | System policy | High-security environments |
| RBAC | Role assignment | Enterprise access management |

## Key Takeaways

- Authorization controls what users can access.
- RBAC is common because it maps access to job roles.
- Access should follow least privilege.
- Authorization models should match business and security requirements.
