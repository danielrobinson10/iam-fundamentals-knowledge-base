# IAM Fundamentals Knowledge Base

## Overview

This repository is a structured Identity and Access Management knowledge base built from my IAM course study notes.

It covers IAM fundamentals, IAAA, authentication, authorization, accounting, IAM standards, Privileged Access Management, Identity Governance and Administration, access governance, role management, lifecycle management, and IAM case studies.

The purpose of this project is to demonstrate my foundational IAM knowledge while building a public portfolio for IAM Analyst, Access Management Analyst, SSO Analyst, PAM Analyst, Identity Governance Analyst, and Junior Identity Engineer roles.

## Note

This project is based on my personal study notes from an IAM course. I reorganized and expanded the material into a structured knowledge base to demonstrate my understanding of IAM fundamentals, IAAA, PAM, IGA, and access governance.

## What This Project Demonstrates

This project demonstrates my ability to:

- Explain core IAM concepts clearly
- Organize identity security documentation
- Understand IAAA principles
- Compare SAML, OAuth 2.0, OpenID Connect, and SCIM
- Explain privileged access risks and PAM controls
- Understand identity lifecycle management
- Document access governance and IGA workflows
- Connect IAM concepts to business risk, compliance, and security operations

## Why IAM Matters

IAM helps organizations ensure that the right users have the right access to the right resources at the right time for the right reasons.

Strong IAM practices reduce unauthorized access, improve security, support compliance, and help organizations manage access throughout the full user lifecycle.
